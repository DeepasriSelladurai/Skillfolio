Skillfolio is a Flask-based skill assessment platform for MSc Computer Science students. It provides student registration and login, topic-based quizzes, review history, performance insights, and an admin dashboard for overview and analytics.

## Features
- Student registration and authentication
- Topic-based quiz experience with scoring
- Review of previous quiz attempts
- Skill profile and chart-based insights
- Admin dashboard for managing student performance data

## Run locally
1. Create and activate a virtual environment
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start the app:
   ```bash
   python app.py
   ```
4. Open http://127.0.0.1:5000

## Tech stack
- Python
- Flask
- HTML/CSS
- Matplotlib
- NumPy
